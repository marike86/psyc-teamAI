# psyc-teamAI

WorkBuddy 专家团「心理支持与有效努力陪伴团」的源码仓库。

## 目录

- `psychological-companion/` — 专家包源码，可直接用于「专家中心 → 我的专家」或开放平台提交：
  - `.codebuddy-plugin/plugin.json`：团队清单与成员展示信息
  - `agents/`：主理人 + 20 位成员的角色定义（21 个 MD）
  - `avatars/`：团队与成员头像（22 张 PNG）
  - `settings.json`、`README.md`、`README.en.md`

## 说明

- 类型：Team（专家团）；版本：1.1.0；分类：12-IndustryConsultant
- 成员展示名为三字花名，职业定位按各自疗法 / 职能区分；原视角名保留在成员表中
- 本团提供 AI 支持，不替代具备资质的真人专业人员的诊断与治疗

详见 [psychological-companion/README.md](psychological-companion/README.md)。
